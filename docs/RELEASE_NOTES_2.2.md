## Дополнительные исправления аудита

- Вход и выход перечитывают сущности; гостевой интерфейс не сохраняет приватные данные предыдущей сессии.
- Права читаются по текущему аккаунту; отключение/сброс пароля/выход отзывают серверные сессии.
- Logout защищён CSRF; нельзя отключить последнего активного администратора.
- Из публичных ответов и поиска исключены secrets, скрытые маркеры/слои и связи с закрытыми записями.
- PRIVATE закрыт для GM/EDITOR также на редактирование, удаление и восстановление по известному ID.
- Восстановление версии не создаёт конфликтующих slug.
- Сериализация полного API read-modify-write защищает от потери одновременных изменений одного процесса.
- Повреждённая база останавливает запуск вместо подмены пустой; seed требует явного --force для перезаписи.
- Неизвестные типы отклоняются; несуществующая запись обрабатывается без браузерного исключения.
- Кириллические slug работают при переходе и перезагрузке; старые ссылки на мигрированные листы перенаправляются.
- При смене типа формы сохраняются несохранённый текст, общие поля и маркеры карты. Неизвестные старые поля не удаляются при обычном редактировании.
- Предупреждение о несохранённых изменениях; безопасная вставка HTML; исправлено наследуемое uppercase-оформление редактора.
- Production-конфигурация требует собственного секрета и первоначального пароля. Удалены встроенные секреты из Compose.

## Совместимость и границы

Миграция сохраняет ID, slug, связи, поля и историю игровых листов. Перед первой миграцией сохраняется копия JSON-базы. Старые сессии нужно переоформить одним входом. Строковые ID исходного проекта сохранены.

Редактор не является Microsoft Word: нет импорта/экспорта DOCX, разбивки по печатным страницам, совместного редактирования в реальном времени. Работает на браузерном contenteditable/execCommand; проверен Chromium. Firefox/Safari требуют дополнительного прогона.

Runtime остаётся однопроцессным JSON-приложением; файл SQL не подключает PostgreSQL. Реальный Docker-хостинг, TLS reverse proxy, многопользовательская нагрузка и полноценный внешний аудит безопасности не проверялись в этом окружении.
