# Аудит исходной версии 2.1.0

Проверены исходники сервера, клиент, маршруты, формы, seed, JSON-база, Docker и исходные тесты. Исходные 8/8 тестов проходят, но преимущественно проверяют API и наличие строк в исходниках, а не браузерные сценарии.

## Найденные проблемы до исправления
1. Лор, Народы, Религии, События, Ветки сюжета, Юниты, Квесты и Сессии отсутствуют в постоянной навигации, хотя сервер знает эти типы.
2. После логина/выхода клиент не перечитывает сущности. Вход показывает гостевой набор, выход оставляет приватные данные в памяти и интерфейсе.
3. Кнопка «Админ» ведёт в профиль; нет доступной авторизованному пользователю ссылки возврата в мастерскую. Cookie уже рассчитан на семь дней.
4. Листы персонажей используют тот же набор characters без разделения назначения/владельца.
5. Юниты и бестиарий имеют урезанные схемы и не используют боевую панель персонажей. Нет опыта, у двух типов нет золота.
6. У предметов отсутствуют КД и урон. Единственное «Свойство» не соответствует требуемой подписи.
7. Редактор поддерживает только несколько команд. Не сохраняет надёжно выделение при работе с панелью; очистка HTML удаляет часть форматирования.
8. Публичный API отдаёт secrets из опубликованных персонажей, скрытые маркеры и ссылки на закрытые записи.
9. Подписанный cookie содержит устаревающие роль и активность. Отключение пользователя/изменение роли/пароля не отзывает старую сессию. Logout не требует CSRF.
10. Сериализована запись файла, но не цикл read-modify-write: параллельные запросы теряют изменения. Ошибки чтения/повреждённая база скрываются пустой базой.
11. Seed перезаписывает существующую базу без подтверждения. Документация рекомендует этот шаг каждому пользователю.
12. Неизвестный тип молча заменяется articles; редактирование неизвестного ID вызывает ошибку клиента; отдельные строки повреждены символами замены.
13. В Docker заданы общеизвестные пароли/секрет. PostgreSQL-схема не подключена к приложению: текущий runtime — JSON, один процесс.

## План
Сохранить существующий дизайн и данные. Открыть все разделы, исправить цикл авторизации, добавить отдельные листы и автоматический перенос игровых characters, общую боевую схему, расширенную панель форматирования. Закрыть выявленные утечки/отзыв сессий/конкурентные записи, обезопасить seed и конфигурацию. Проверить API и реальный интерфейс Chromium с изолированной тестовой базой, затем упаковать исходники и отчёт.
