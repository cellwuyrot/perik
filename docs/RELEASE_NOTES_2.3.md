# Ashan Arcanum 2.3.0 — реализация правок

## Принятые решения по противоречиям

- Повторные переименования трактуются как последовательные уточнения: итог — «Витрина» и «Каталог», а не промежуточные «Оглавление»/«Архив».
- Более конкретное требование удалить категорию и ранг у юнитов/бестиария имеет приоритет над общей строкой про перенос категории/ранга наверх. Категория отсутствует у всех трёх типов; титул есть только у персонажей и находится сверху.
- Фразу «убрать добавить … колонку урон» трактуем как добавление урона к верхним сведениям; следующие строки отдельно уточняют отсутствие урона у персонажей/бестиария. Добавлено всем трём типам.
- «Интерелект» исправлено на «Интеллект», первая характеристика отображается кириллической «С».
- Удаление разделов выполнено на уровне интерфейса, без разрушения прежней базы и истории. Совместимый API старых типов сохранён; разделы и страницы этих записей больше не отображаются в приложении.
- Поиск удалён из левой колонки, не из всего приложения.

## Главная рамка и витражи

Прежние статические текстовые блоки главной страницы удалены. Настройки начинаются пустыми. ADMIN редактирует тексты, загружает карточки, задаёт порядок, дату начала и часовой пояс. Ротация общего набора карточек — ежедневно по календарю, после полного цикла начинается заново. Встроенное обновление открытой главной страницы проверяет смену дня с интервалом 30 секунд. Файлы PNG/JPEG/WEBP/GIF до 5 МБ, до 60 карточек. Изображения можно заменять без правок кода.

Для остальных карточек каталога уже существовавший механизм загрузки обложек остаётся доступен в редакторе каждой записи.

## Сохранность и безопасность

Изменения глобальной витрины защищены ролью ADMIN и CSRF. Загрузки используют существующую защищённую медиатеку. Настройки валидируют дату, часовой пояс, число карточек и безопасный URL. Вывод текстов экранирован/санитизирован; изменения регистрируются в аудите. Поля прежних типов сохраняются, неизвестные пользовательские поля не теряются при редактировании. Перед миграцией предыдущей схемы создаётся копия `.pre-2.3-backup`.

Архив не содержит результатов ручной работы в реальной production-базе. Включённая `data/db.json` — демо из исходного архива с совместимой миграцией.
