# AEtheria v2 — архив RPG-мира

Самодостаточное приложение на Node.js 22+ и vanilla JS/CSS. После распаковки запускается без установки зависимостей.

## Запуск

```bash
npm run seed
npm start
```

Откройте `http://localhost:3000`. Пользовательская кнопка «Войти» ведёт на регистрацию/вход игроков. Скрытый вход администратора доступен только по адресу `/enter`; ссылки на него в интерфейсе нет.

Администратор при первом запуске: `admin@example.com` / `change-me-now`. Перед публикацией задайте `ADMIN_NICK`, `ADMIN_PASSWORD` и длинный `SESSION_SECRET`.

## Основные возможности

- новая редакционная сетка без тяжёлых карточек; встроенные кириллические шрифты;
- единый чёткий SVG-набор интерфейсных иконок;
- регистрация по нику и паролю с автоматическим созданием персонажа;
- роли ADMIN / GM / EDITOR / PLAYER и управление доступом;
- rich-text редактор, форматирование и @mentions;
- история редакций и восстановление;
- прямая загрузка обложек и изображений с компьютера в редактор, без ручного URL;
- медиатека PNG/JPEG/WEBP/GIF/PDF;
- ветви сюжета, специализированные поля сущностей и кампаний;
- карта со слоями, фильтрами и скрытыми GM-областями;
- фильтруемый граф связей мира;
- журнал сессий, персонажи, кампании, квесты, события и энциклопедия;
- динамические title/description/Open Graph/canonical для публичных страниц;
- аудит действий, rate limiting, CSRF, CSP, HttpOnly-сессии, PBKDF2;
- адаптивность, keyboard focus, reduced motion и семантические роли;
- PostgreSQL 16 production-схема в `db/schema.sql` и план развёртывания в `docs/PRODUCTION.md`.

## Проверка

```bash
npm test
node --check server.mjs
node --check public/app.js
```

## Хранение данных

Портативная сборка использует `data/db.json` и `data/uploads`. Запись выполняется атомарной заменой файла. Для многопроцессного production-развёртывания перенесите repository-слой на PostgreSQL по готовой схеме `db/schema.sql` и вынесите медиа в S3-совместимое хранилище.
